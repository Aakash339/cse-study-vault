# CSE Study Vault

A centralized web application developed to provide Computer Science students with easy access to semester-wise study resources, including notes, model papers, lab programs, and important questions. The platform includes an admin panel for efficient resource management and a simple, user-friendly interface for students.

---

##  Features

- Semester-wise study material organization
- Student dashboard for easy navigation
- Admin panel to manage academic resources
- Secure login system
- Responsive and intuitive user interface

---

##  Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- MySQL

---

##  Prerequisites

- Python 3.10+
- MySQL Server
- pip

---

##  Installation

1. Clone the repository

```bash
git clone https://github.com/Aakash339/cse-study-vault.git
```

2. Navigate to the project folder

```bash
cd cse-study-vault
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Configure the MySQL database.

5. Run the application

```bash
python app.py
```
